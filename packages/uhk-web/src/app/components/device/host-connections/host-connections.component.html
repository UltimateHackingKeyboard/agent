Multipoint operation

Keeps every connected Bluetooth host connected instead of dropping the old connection when you switch to another host. Without this, the UHK operates in singlepoint mode like most Bluetooth keyboards: it talks to one host at a time.

Pros:
  • Instant switching between connected hosts
Cons:
  • Stuttering mouse movement (due to BLE scheduling conflicts)
  • Increased latency
  • UHK permanently stealing input focus of non-active but connected hosts (e.g. the on-screen keyboard not popping up)

Keeps the UHK discoverable even while it is already connected, so a further host can connect without you having to free up a connection first.

Pros:
  • Hosts can pair or connect without dropping an existing connection first
Cons:
  • Security risk: nearby infected devices can easily detect the UHK and try to exploit possible vulnerabilities
  • Privacy risk: others may snoop on advertising
  • Neighbors may try to connect, causing unnecessary nuisance
  • Aggressive reconnection loops
